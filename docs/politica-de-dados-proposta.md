# Política inicial de tratamento de dados — PROPOSTA

> Documento técnico de apoio, **sujeito a validação institucional** (SENAI, encarregado de dados
> e coordenação). Não substitui a política oficial da instituição nem orientação jurídica. Há
> estudentes menores de idade: seguir as orientações institucionais aplicáveis.

## Finalidade

Organizar a Maratona de Competências SAEP: duplas, encontros, atividades, avaliação, pontuação,
ocorrências e classificação.

## Dados previstos (minimização)

| Categoria     | Exemplos                      | Quem acessa (RLS)                                                       |
| ------------- | ----------------------------- | ----------------------------------------------------------------------- |
| Identificação | nome, e-mail institucional    | a própria pessoa; coordenação da edição; docentes das turmas vinculadas |
| Vínculo       | papel, edição, turma, dupla   | a própria pessoa; coordenação                                           |
| Atividades    | respostas, entregas, arquivos | a dupla; docentes vinculados; coordenação                               |
| Avaliação     | rubricas, presença, feedback  | a dupla; docentes vinculados; coordenação                               |
| Prova oficial | realização e nota confirmada  | **restrito**: o próprio estudante e coordenação autorizada              |
| Ocorrências   | fato, evidência, decisão      | **restrito**: envolvidos, docente responsável, coordenação              |
| Auditoria     | autor, ação, horário          | coordenação                                                             |

Não coletar: CPF, endereço, telefone, dados de saúde ou documentos pessoais, salvo decisão
institucional formal.

## Regras técnicas já aplicadas

- RLS por perfil e vínculo; sem acesso anônimo às tabelas.
- Ranking exibe somente totais da dupla; nenhuma nota individual pública.
- Service worker não armazena dados autenticados.
- Seeds e demonstração somente com dados fictícios.

## A definir pela instituição

Base legal e termo de ciência; prazo de retenção após a edição (sugestão para avaliação:
anonimizar ou excluir dados individuais após o encerramento e o prazo de recursos); quem pode
exportar dados; procedimento para pedidos de acesso/correção; responsáveis e contato.
