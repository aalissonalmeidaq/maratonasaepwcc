# Módulo: Edições, cursos e turmas

**Responsabilidade:** cadastro de edições com regras versionadas, cursos/categorias e turmas (RF02).

**Situação:** esquema e RLS criados na spec 001; telas de cadastro no Incremento 2.

Estrutura prevista: `domain/` (TS puro), `data/` (repositórios Supabase), `ui/` (React) e
`index.ts` (API pública). Ver `docs/arquitetura.md`.
